# 火起こし × ローグライク 設計メモ

一晩の議論のまとめ。ゼロから読み返して、どこまで決まっていて何が未着手かを思い出すための文書。

## 0. 一行で言うと

**世界のすべての火が消えた後、燃料を正しい順序でくべて温度を上げ、七つの太陽を昇らせながら世界を焼き尽くすデッキ構築型ローグライク。**

---

## 1. なぜ火とギャンブル／ローグライクが噛み合うのか

議論の出発点になった観察。

- **燃焼は正のフィードバック**（熱 → 燃焼速度↑ → 熱↑）。指数関数的な伸び＝インフレの理屈が物理の側から用意されている。
- **破滅が二種類ある**。「消える」と「爆発する」。伸ばす／飛ぶの両方が説明抜きで直感的に通じる。
- **火は所有できない**。持ち越せない。毎回ゼロから起こすしかない。→ ローグライクの「毎ラン初期化」がテーマ側から完璧に正当化される。

この三点目が最重要。**メタ進行に炎そのものを繰り越してはいけない**。引き継ぐのは技法だけ（「弓錐式を覚えた」「松脂の性質を知った」）。火は消えるが、火の起こし方は残る。

## 2. コアメカニクス

### 2.1 常時圧力：熱は放っておくと逃げる

スロット系は「回さない」選択ができるが、火は**焚べ続けないと死ぬ**。ここが差別化点。

- 燃料を投入 → 温度が上がる
- 何もしないと温度は下がる（減衰）
- この減衰の名前を **「メトラ」**（ヘラクレイトスの「定めの分だけ燃え、定めの分だけ消える」より）にする案

**敗北条件＝HP ゼロではなく、温度が着火点を下回った瞬間**。

### 2.2 上限は置かない（重要な方針転換）

初期案では「炉の耐熱温度」を上限に置いたが、**却下**。理由は、伸ばすほど怖くなる構造はインフレゲームの爽快感を殺すから。

代わりに **相転移** を置く。温度が閾値を超えたとき、炉は壊れるのではなく**用済みになる**。

- 石の炉が溶ける → 溶けた炉自体が燃料になり、地面に直接置かれた火になる
- その火が大気を焼き切る → 火は容器を必要としなくなる（脱・炉）
- 最終的に火は場所を持たず、概念として燃えている

プレイヤーから見ると「限界を突破した」という**報酬イベント**。ペナルティはゼロ。天井は罰ではなく到達点。

### 2.3 燃料に持たせる4つの値

燃料は「点数」ではなく**性質の束**にする。

| 値 | 役割 |
|---|---|
| **着火点** | これ以上の温度がないと火がつかない（＝順序を縛る） |
| **発熱** | 温度への寄与 |
| **持続** | 何ターン燃え続けるか（同時燃焼数が酸素倍率の土台になる） |
| **タグ** | 樹脂／粉／金属／湿／油／概念。コンボの引き金は全部これ |

### 2.4 順序が爆発を生む3つの仕組み

1. **着火伝播** — 燃料は投入順にスタックされ、火は下から上へ伝わる。着火点の低い順に積めば全段に燃え移り、途中に着火点の高いものを挟むと**そこで伝播が止まって上が全部死ぬ**。
   - 例：麻屑(0) → 乾いた薪(180) → 炭(300) → マグネシウム(473) は全段着火
   - 例：麻屑(0) → 生木(620) → 薪 → 炭 は生木で止まり上二段が不発
2. **触媒** — 松脂は「直後に積んだ燃料の発熱を ×3」。触媒同士を隣接させると触媒が触媒を強化する。
3. **タグ共鳴** — 同じタグを3連続で指数化。「粉」が2つ以上あると**粉塵爆発でスタック全体が再点火**（累計にもう一度倍率が乗る）。1ランの最大火力を作る場所。

### 2.5 伸び方の実例

> 麻屑で着火 → 薪(+10) → 松脂(次×3) → コークス(+30→90) → マグネシウム(粉1) → 小麦粉(粉2→粉塵爆発、スタック全体再点火で累計×5) → 送風(同時燃焼6本→×6) → 炎そのもの(現在温度ぶん加算→×2)

この8手で 10 → 5,400。同じ構造が階梯を上がるたびに桁ごと繰り上がる。**爆発の原因が全部プレイヤーの並べ方にある**ので、伸びたときに気持ちよく、伸びなかったときに納得できる。

### 2.6 操作粒度

毎ラウンド全部を手作業で並べると重い。**手札から4〜5本選んで積む**くらいが現実的。

## 3. 燃料リスト（階梯別）

### 第1階梯・焚き火（順序パズルを教える段階）
麻屑（着火0、発熱1、他の全燃料の着火点を下げる）／杉の葉／松ぼっくり／乾いた薪（安定の基礎）／**松脂**（触媒、次を×3）／炭（発熱低・持続長、酸素倍率の土台）／生木（着火点が異常に高い罠。後半で「湿」タグとして化ける）

### 第2階梯・産業炉
コークス／重油（油タグ、周囲3段に延焼）／**送風**（燃料でなく行動。同時燃焼本数だけ全体を倍化）／マグネシウム（粉＋金属）／小麦粉（粉タグの純粋な爆薬、単体では発熱ほぼゼロ）／テルミット（金属タグ3つ以上で発動、単発の巨大バースト）／酸素ボンベ

### 第3階梯・破綻（現実味を捨てる境目。一番おいしい）
**水**（着火点が桁違いに高いが、超えると熱分解して最大級の燃料に）／石／**灰**（これまでに燃やした燃料の平均値で燃える）／**炎そのもの**（発熱＝現在温度、つまり毎回2倍）／雷／**燃えない何か**（燃えないことによって場の全燃料の着火点を無視させる）

### 第4階梯・概念
時間（持続∞、毎ターン発熱が倍化）／記憶／名前（直前に使った燃料をコピー）／太陽／「熱」という語／因果（積んだ順序を後から並べ替えられる）

### 温度＝対数スケール＝色

得点が 10⁹ になっても、プレイヤーは数字でなく**炎の色**で理解できる。黒体放射がそのまま UI になる。

| 段階 | 倍率 | ルール変化 |
|---|---|---|
| 燻り | ×1 | 水で即死 |
| 赤熱 | ×10 | 鉄が溶ける |
| 橙炎 | ×100 | 延焼開始 |
| 白熱 | ×1,000 | **水も燃料になる** |
| 青炎 | ×10,000 | 炉が意味を失う |

段が上がると**倍率だけでなくルールが反転する**のが肝。低温では水は即死級のリスクだが、白熱域では熱分解して燃料に変わる。序盤のデバフカードが終盤の最強カードになる。同じことを風でもできる（弱火では吹き消される／強火では酸素供給になって倍率化）。

## 4. 目的とループ

### 4.1 「なぜ火起こしなのか」への答え

**火は目的ではなく手段だから。** 温度を上げるだけでは火起こしが目的化してぼやける。**燃やせない何かを目の前に置いた瞬間**、温度が意味を持つ。

### 4.2 ノルマを数字ではなく「物」にする

Clover Pit の家賃にあたるものを、金額ではなく**発火点を持った対象**にする。

- 「なぜ 10⁹ 度が必要なのか？」→「海を燃やすから」
- 数字が大きくなるのではなく、**燃やす対象がおかしくなっていく**
- プレイヤーが見るのはスコアではなく、目の前の物が燃えるかどうか

### 4.3 コアループ

**くべる**（順序と触媒で温度を作る）→ **燃やす**（対象の発火点を超える）→ **灰を拾う**（燃やした対象が新しい燃料としてデッキに入る）→ 繰り返し

鉄の門を燃やせば「鉄」が、海を燃やせば「水」が手札に加わる。**デッキ構築の報酬が倒した敵そのもの**になるので、「なぜこれが手に入るのか」で悩まなくて済む。

### 4.4 ローグライク構造

- **1ラン＝一晩**。夜明けまでに火を消さずに進む
- **分岐ノードマップ**（Slay the Spire 式）：森＝燃料採取、廃屋＝触媒、雨雲＝リスク（温度は下がるが越えれば湿タグの上位燃料）、旅商人＝焚き火を売る男
- **エリアボス＝燃やせない物**
- **レリック＝火にまつわる道具**：火打石、鞴、風袋、灰の壺、消えない燠

## 5. 世界観の元ネタ

### 5.1 採用：七つの太陽（仏教・壊劫）

出典は『七日経』（増支部）、『起世経』、『長阿含経』世記経、『倶舎論』など。**太陽が一つずつ増えていく**。二つ目で小川が涸れ、三つ目で大河が、四つ目で大湖が、五つ目で大海が涸れ、六つ目で大地と山が煙を上げ、七つ目で須弥山までが炎に包まれて梵天界まで焼き尽くす。

#### 世界の構造（何を燃やすかの地図）

世界は虚空に浮いているのではなく、**三つの層に支えられている**。

```
        初禅天（火が届く上限）
             須弥山（世界の軸）
        大地・九山八海
        金輪（凝固した層）
        水輪
        風輪
             虚空
```

大地は最下層ではない。**風の上に水が載り、水の上に金属が載っている**。この入れ子が「依存の階梯」にそのまま使える。

#### 時間の構造（四劫）

**成劫**（形成）→ **住劫**（存続）→ **壊劫**（破壊）→ **空劫**（空白）の無限反復。七つの太陽は壊劫の局面。

破壊の順序が重要で、**まず有情世間（生き物の世界）が壊れ、その後に器世間（物理的な入れ物）が壊れる**。生き物は先に禅定を得て上位の天へ避難し、地上から誰もいなくなってから火が始まる。

→ **七つの太陽が昇るとき、世界はすでに無人**。プレイヤーは誰も助けず、誰にも見られず、空っぽの世界を焼く。孤独と静けさが担保される。

#### 三災と「七」の入れ子

破壊は火だけではない。**火災・水災・風災**の三種があり、届く深さが違う。火は初禅天まで、水は二禅天まで、風は三禅天まで。四禅天だけがどれにも壊されない。

順序も入れ子で、**火の壊劫が七回続いた後に水の壊劫が一度**来る。それが七巡した後に風の壊劫が一度来る。七の中に七があり、その上にまた七がある。

→ 「**火には焼けないものがある**」設定は終盤に効く。第七の太陽に到達してもまだ上に焼けない層が残る＝次の周回の動機。しかも周回ごとに手段が変わる（火 → 水 → 風）という拡張余地。

### 5.2 デフォルメの原理

原典の階梯（川→大河→湖→海→大地→山→須弥山）は**スケールが大きくなっているだけ**で、そのままでは「デカい水たまりの次にもっとデカい水たまり」になってしまう。

抽出すべきは、**燃やすたびに世界を成立させている前提が一枚ずつ剥がれていく**という構造。海が涸れるのがすごいのではなく、海が涸れた世界がもう元に戻らないのがすごい。

→ 軸を **大きさ** から **依存** に差し替える。「それが無くなったら、上に載っているものが全部崩れるか？」を基準に並べる。

### 5.3 アクセント：ヘラクレイトス

一番ゲームに向いているのは「宇宙は火である」ではなく、**「万物は火の交換物であり、火は万物の交換物である。金と商品がそうであるように」**。これは経済の比喩なのでそのままシステムになる。

- **すべてのものに「火の値段」がある**。燃やす＝両替。だから概念も感情も燃やせる。第七章で法則を燃やせる理屈がここで通る
- **メトラ（定めの分だけ燃え、定めの分だけ消える）** → 毎ターンの熱損失の名前に
- **万物流転／同じ川に二度入れない** → 「同じ火は二度と起こせない」＝ランダム生成の口上
- **戦いは万物の父** → 湿と乾、水と火のタグ相互作用に添える
- **エクピュローシス**（宇宙は周期的に焼かれ同じ形で再生する） → 周回の正当化

### 5.4 その他の引き出し（未採用だが使える）

- **新火の儀式（アステカ）** — 52年ごとに帝国じゅうの火を一つ残らず消し、神官が星の丘で錐揉みで新しい火を起こす。灯れば世界は続き、灯らなければ終わる。**ラン構造の物語的正当化として最高**。火の老神ウェウェテオトルは頭に火鉢を載せた老人の姿
- **スルトとムスペルヘイム（北欧）** — 火の国は世界の始まりでもあり終わりでもある。ループ構造の説明に
- **アグニ／護摩（インド）** — 燃やすことは捧げること。「燃やしたものが燃料になる」に神学的理屈を与える。カーラーグニ＝時の火
- **カグツチ（日本）** — 生まれた瞬間に母を焼き殺し、その死体の断片から山の神々が生まれる。カード獲得ループの直接の元ネタ
- **フラショー・クルティ（ゾロアスター教）** — 世界の終わりに溶けた金属の川が全地を流れる。金属階梯の名前に
- **燔祭 / holocaust** — 一部でなく全部を焼く供物
- **華氏451度** — 「発火点を対象のステータスにする」発想の先祖

## 6. 七章構成（燃やす対象）

各章のボスは**物ではなくカテゴリ**。同じ章の中で **物理 → 現象 → 抽象** へ滑らせるのが肝。

| 章 | カテゴリ | ボス案 | 備考 |
|---|---|---|---|
| 一・熾 | いま燃えているもの | 枯野／打ち捨てられた村／最後の薪 | 教科書。順序と触媒を覚える |
| 二・流 | 流れるもの | 大河／人の一生／噂 | 発火点は「流れが速いほど高い」。止めてから燃やすか流れごと燃やすか |
| 三・淵 | 湛えるもの | 底の見えない湖／誰かの記憶／沈黙 | 湿タグの壁が本格化。「水も燃料」への転換点 |
| 四・満 | 満ちるもの | 大海／大気／潮の満ち引き | 大気を燃やすと**以後 酸素が有限になる**（恒久ルール改変） |
| 五・輪 | 世界を支える三層 | 金輪／水輪／風輪 | **最大の見せ場**。土台を下から抜く。三体倒すと世界が宙に浮き、以後すべて虚空で戦う |
| 六・軸 | 動かないもの | 九山八海／須弥山／方角 | 中心を燃やすと上下と東西南北が失われる |
| 七・限 | 火が届く限界 | 初禅天／劫という時間／**火** | 最後に自分自身を燃料としてくべる |

### 太陽のメカニクス化

- 章をクリアするたび、空に**太陽が一つ増える**
- 太陽は以後すべての温度に乗り続ける（第 n 章では ×n）
- **太陽が増えるほど世界は乾き、燃料の着火点が下がる** → 後半ほど何もかも燃えやすくなる。インフレ加速の物理的な言い訳
- 七つ目が昇った瞬間、ラン終了。全部が燃える

### 最後の一手

第七章で燃やす対象を**火そのもの**にすると、二つの元ネタが一点で交わる。万物が火の交換物なら、最後に残った火を燃やすことは万物を燃やすことと同義。そしてエクピュローシスの通り、焼き尽くされた宇宙はまた同じ形で始まる——**次のランへ**。

「なぜまた最初から火を起こすのか」に、ゲームが自分で答えている状態。

## 7. 検討したが却下／保留した案

| 案 | 結論 | 理由 |
|---|---|---|
| 炉の耐熱＝上限、超えたらラン終了 | **却下** | インフレの爽快感を殺す。相転移に置き換えた |
| スロット型（Clover Pit 直系） | 保留 | 演出は華やかだが、火の性質（燃え続ける・逃げる・酸素が要る）を活かしにくく、リールが火である必然性が薄い |
| バッグビルド（クアックサルバー式） | 部分採用 | プッシュユアラックは魅力的だが、最終的にカード／デッキ構築型へ寄せた |
| 目的案①「運火」（山頂まで運び太陽に火をつける） | 保留 | 方向性の一貫性は最良 |
| 目的案②「越冬」 | 却下寄り | 情緒は強いが、燃やすほど失うものが増え爽快感と逆行 |
| 目的案③「焚書／終焉」 | **採用** | 七つの太陽と接続して現在の形に |
